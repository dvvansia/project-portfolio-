CubeSat OBC Power Distribution Unit

KiCAD 9.0 • 4-Layer PCB • INA199 Current Sensing

Flight-grade power distribution system for 1U CubeSat OBC with 4 regulated rails (3V3_DIG, 3V3_ANA, 5V0_IO, 3V3_MEM), comprehensive protection (reverse polarity, overcurrent, thermal), and telemetry feedback via INA199 high-side current sense amplifiers.

  • 8-sheet hierarchical KiCAD schematic (ERC passed: 0 errors)
  • LM5050-1 ideal diode ORing + TVS protection
  • REF5033 precision reference for analog rail (3.3 µVrms noise)
  • 16-pin OBC backplane connector with fail-safe boot pull-downs
  • Full telemetry: 4× current monitors + battery voltage divider
