# Satellite Avionics & Embedded Systems Portfolio

Professional engineering portfolio of **Dhruvrajsinh Vansia**, an MSc Space Sciences and Technologies student at the University of Bremen.

The portfolio presents spacecraft-oriented projects across:

- Satellite avionics
- Power conversion and distribution
- Sensor electronics
- Embedded data acquisition
- RF communication analysis
- Computer vision and machine learning

## Featured projects

### CubeSat OBC Power Distribution Unit

A design-stage CubeSat-oriented power-distribution system with regulated rails, circuit-protection concepts, current sensing and telemetry interfaces.

Repository:

[CubeSat OBC Power Distribution](https://github.com/dvvansia/CubeSat_OBC_Power_Distribution)

### Satellite-Oriented Sensor Node

A completed sensor-node schematic integrating environmental sensors, an ATmega328P microcontroller, 3.3 V regulation and an XBee communication interface.

Repository:

[Satellite Sensor Node](https://github.com/dvvansia/Satelliet_Sensor_Node)

## Project maturity policy

Project status is stated explicitly throughout the website.

Examples include:

- Design stage
- Schematic complete
- LTspice simulation
- Proteus simulation
- Software analysis tool
- Embedded project

Simulation and design-stage work is not represented as fabricated, environmentally tested or flight-qualified hardware.
